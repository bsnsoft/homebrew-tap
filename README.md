# Homebrew tap of BSNSoft Solutions GmbH

    brew install bsnsoft/tap/esj

`esj` is the command line tool of [EN 16931 Semantic JSON](https://github.com/bsnsoft/esj): read,
validate, convert and render e-invoices (UBL, CII, Factur-X/ZUGFeRD, ESJ). The formula installs the
native executable of a release and verifies its checksum.
